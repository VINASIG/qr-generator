# Security

Report a vulnerability privately through the repository's GitHub private vulnerability reporting channel when it is enabled. Do not include real Wi-Fi passwords, confidential URLs or personal data in public issues.

The app generates static QR data and does not open or validate a destination website. A QR code's ability to decode does not establish that its contents are trustworthy. Synthetic fixtures are used for checks. Payloads are not uploaded, persisted or inserted as HTML. Dependency auditing is one maintenance check and is not an independent security audit.
