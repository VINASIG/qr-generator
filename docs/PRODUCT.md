# Product decisions

The owner's brief asks for a clean traditional QR generator and authorizes standardization and public publication under VINASIG. The follow-up of 3 October 2026 asks for useful additional content formats and technical controls, with advanced controls collapsed by default. This product adopts Bright Playful Minimalism from the design system for this scope.

## Primary task

Choose one of nine content types and enter its fields. The preview and downloads update automatically after a 200 ms pause in input. Technical options and PNG size also update the output without a creation button. Only the selected fieldset is visible and enabled. The URL or text mode keeps exact untrimmed input without rewriting, shortening or fetching it. Blank content, unsupported controls, incomplete Unicode and built payloads over 2,000 UTF-8 bytes are rejected. This is an application cap; content must also fit the selected correction level and version. It includes percent-encoding and format overhead.

Wi-Fi escapes reserved characters, quotes hex-looking literal values, supports hidden networks and drops a previous password when an open network is chosen. SSID is limited to 32 UTF-8 bytes and the password to 128 bytes. Personal WPA/WPA2, WEP and open payloads are supported; enterprise authentication is not provided.

## Advanced settings

The standard Model 2 encoder automatically segments numeric, alphanumeric and UTF-8 byte content. Advanced settings start closed:

- Error correction: L/M/Q/H, default M. Approximate 7/15/25/30% recovery concerns total codewords, not a guaranteed percentage of surface that can be covered. Higher correction can require a denser code.
- White border: 4, 8 or 12 modules; no option below the four-module minimum.
- Version: Auto (smallest that fits) or 1-40. Too-small explicit versions report the fitting minimum; they are never silently overridden.
- Mask: Auto (encoder selection) or 0-7. A manual mask may have a worse pattern penalty and does not change content.

The actual encoder checks capacity, including efficient numeric/alphanumeric segmentation. At version 40, byte-only capacities are L 2,953 / M 2,331 / Q 1,663 / H 1,273 bytes before the application's 2,000-byte cap. These are not universal character limits. Oversized/incompatible input gives a correction and keeps downloads disabled.

Micro QR, rMQR, SQRC, Frame QR, GS1/FNC1, structured append and arbitrary binary files are outside this encoder/product scope.

## Output and state

The app builds one selected matrix for both outputs. SVG contains only a white rectangle and black vector runs with the selected module margin. PNG centers integer modules inside the selected dimensions with at least the same margin. There are no logos, colored dots, transparent backgrounds or watermarks. A collapsed inspector shows actual byte count, version/grid, correction, mask, border and PNG pixels per module.

Editing content or technical options, changing type or PNG size immediately clears the previous preview, inspector values and downloads, then schedules the new output. Revealing a password or opening a disclosure does not change content. A generation revision prevents an asynchronous PNG callback from restoring an outdated result, including after Clear. IME composition postpones generation until composition ends. Clear remains usable during generation.

Incomplete input does not produce a code. Input errors appear when the affected field loses focus or the user explicitly submits with Enter. Capacity errors appear after the scheduled encoder check. Automatic updates and errors retain input focus, scroll position and disclosure state. Enter may focus the invalid field and reveal its disclosure. Clear resets all nine types, checkboxes, settings and PNG size, closes extras/settings and focuses URL/text. Temporary object URLs are revoked on replacement and exit. Download URL cleanup never changes the settings or preview. SVG never embeds input as markup or external references.

Custom dropdowns and date calendars use the VINASIG typography and semantic colors with keyboard and touch support. Checkboxes, text date/time inputs and disclosures retain semantic form behavior. Client inputs and actions start disabled until the required handlers are installed. Absent or blocked scripts leave static explanations available and cannot submit content. Motion stays limited to the existing fine-pointer button response and disappears for reduced motion.

## Privacy and delivery

Creation and export run locally with bundled code. No payload storage, remote QR API, destination fetch, analytics, account, hosted redirect or server application is added. Payloads are not put in page URLs, filenames, logs or telemetry. Calendar UUIDs and timestamps exist only as local event-format metadata. Browser/OS tools may independently retain downloads/input. Hosting sees normal page requests. Anyone receiving a code can decode its contents.

Batch generation, campaigns, subscriptions, scanning, logo styling, clipboard/camera/location permissions and persistent PWA caching need a separately demonstrated task. A social profile, video, payment page or externally hosted document can already be a direct URL; duplicate provider-specific modes add controls without changing that format.
