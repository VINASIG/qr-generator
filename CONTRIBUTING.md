# Contributing

Read AGENTS.md and docs/PRODUCT.md. Preserve the local-only static contract and the short generation flow. Use pinned versions, run source/unit/build checks and include browser evidence for visible behavior. A generated QR must decode to the exact requested payload without a VINASIG redirect or embedded branding.

Keep screenshots and traces in ignored output/. Document findings under docs/audits/. Do not weaken checks, approve a broken baseline, add telemetry or publish changes outside the current authorization. Source and commit subjects use English. See LICENSE_STATUS.md before redistribution.
